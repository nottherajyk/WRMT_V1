# Hyperframes Composition Brief: wherearemytools

## Objective
Create a short, energetic, neo-brutalist launch brag video for wherearemytools.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: landscape — 1920x1080
- Duration: 18 seconds

## Source Material
- Project root: `d:\PROJECTS\AIOT`
- Primary files read: index.html, src/style.css, src/tools-data.js, src/main.js
- Product name: wherearemytools
- Tagline / strongest claim: "All-in-One Free Online Tools. 50+ Tools. Zero Signup. 100% Browser Local."
- Key UI or visual moment to recreate: Neo-brutalist category pill cards, dropzone file processing, instant download action.
- Copy that must appear verbatim:
  - "WHERE ARE MY TOOLS?"
  - "50+ Tools. Zero Signup."
  - "100% Free • Client-Side • Private & Fast"
  - "wherearemytools"

## Creative Direction
- Tone preset: `default`
- Creative direction: Loud Neo-Brutalist Show & Tell
- Interpretation: Fast-paced entrance, sharp offsets, high-contrast neon yellow & hot pink palette, punchy bold fonts, zero corporate fluff.
- Angle: Highlight the sheer variety and instant browser-based privacy of 50+ free tools with bold Starface Neo-Brutalist design.
- Hook: A giant pitch-black card slams onto a bright neon yellow background: "WHERE ARE MY TOOLS?" followed by "50+ Tools. Zero Signup."
- Outro / punchline: "Stop searching. Start building." -> wherearemytools
- Avoid:
  - Generic SaaS language
  - Abstract filler visuals
  - Boring corporate gradients or pill buttons

## Visual Identity
- Background: `#FAFF05` (Starface Neon Yellow)
- Text / Borders: `#000000` (Pitch Black with 6px-10px flat offset shadows `shadow-lg`)
- Primary Accent: `#FF007F` (Starface Neon Hot Pink)
- Secondary Accents: `#00D2FF` (Sky Blue), `#16C641` (Green), `#FFB000` (Orange)
- Display font: `Fredoka`, sans-serif
- Body font: `Space Grotesk`, sans-serif

## Storyboard Summary
1. **Scene 1 — The Hook (3.5s)**: Neon yellow screen. Heavy black card slams: "WHERE ARE MY TOOLS?". Neon pink pill pops: "50+ Tools. Zero Signup."
2. **Scene 2 — Category Grid & Tool Power (5.0s)**: 4 neo-brutalist tool cards pop in 1-by-1 with sharp drop shadows: Image (#00D2FF), PDF (#16C641), Social (#FF007F), Text (#FFB000).
3. **Scene 3 — Instant Browser-Local Flow (5.0s)**: Simulated browser box. File dropped -> progress bar fills 0 to 100% instantly -> "100% Client-Side • Private & Fast".
4. **Scene 4 — Outro / CTA (4.5s)**: Banner slams: "Stop searching. Start tools." URL card pops: **wherearemytools.com**.
